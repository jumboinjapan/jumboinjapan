# Матрица POI: пилот M4 на 50 карточках

15.09.2026. **Пилот выполнен; весь этап M4 ещё не завершён.**
Создано одно поле POI Matrix (multilineText). Записаны 50 матриц и 186 свойств,
каждое с основаниями из досье. Два автора и отдельный редактор проверили смысл
всех предложений. Данные получены из сохранённых фактов; нового обхода источников
и вызовов Google не было. Изменяемые свойства действуют 14 дней от оценки;
их продление требует повторной проверки, а не перестановки даты.

## Что изменилось

Существующий poi:sync получил пакет poi-matrix-update/v1: он пишет только матрицу.
Досье, описания, прежний тип, статусы, координаты и связи сохранены. Исполнитель
не создан заново: используются прежние lock, бюджет, журнал, свежее чтение
и проверка после PATCH. При повторе уже применённые строки пропускаются.

У старых досье ключ вида poi:POI-xxxxxx принимается только при точном совпадении
POI ID. Добавленный позднее ключ портала не делает такое досье чужим.
Пустая прежняя категория у 12 карточек пилота не мешает поиску по доказанным
свойствам. Поля прежней классификации этим пилотом не заменялись.

## Приёмка

Полный npm run verify на Node 22.23.0: exit 0, включая 85 наборов и build.
Узкий набор записи: 36 проверок. Шесть мутаций остановлены именованными
утверждениями. Независимый аудит кода и семантическая проверка — ACCEPT.
Первый запуск verify выполнялся во время правки графа и остановился в тесте
защиты от изменения кода; полный повтор на неподвижном дереве прошёл.

Независимо перечитаны все 1146 записей таблицы (1135 обычных POI и 11 системных).
Ровно у 50 изменилось POI Matrix; другие поля и остальные записи совпадают
со снимком до пилота. Порции: два пакета по 25. Неопределённых исходов нет.
Повторная проверка: 50 noChange, 0 PATCH. Живой интерфейс: 50 проверенных,
1085 незаполненных, 0 повреждённых матриц. Общий reader отдельно проверен
для замков, аквариумов, гор, музеев и возраста 8 лет: без доказанных детских
условий такой подбор возвращает пустую выборку. В браузере выбор замков
и аквариумов дал ровно Мацумото, Хиноэ и океанариум Камо; метки свойств видны.
Артефакты: tmp/matrix-m4-2026-09-15/ — execution-card.json, base-before.json,
schema-journal.ndjson, packet-1.json, packet-2.json, semantic-review.json,
readback.json, verify-final.log, verify.exit, mutations.json.
Журналы записи — tmp/poi-jg-copy-runs/m4-pilot-1/ и m4-pilot-2/.

## Остаток M4

Матрица пока не заполнена у 1085 POI: 683 ожидают оценки по имеющемуся досье;
401 требует фактического досье, ещё 1 — уточнения предмета фактов.
Из 270 карточек с неопределённым прежним типом 12 получили матрицу в пилоте,
21 имеет досье для следующей оценки, 237 требуют сбора фактов. Это пересекающийся
срез той же базы, а не дополнительные карточки. Следующая очередь начинается
с этих 21; затем идут остальные пригодные досье и исследовательский остаток.
Старый фильтр типа сохраняет число 270, поскольку перенос старых категорий
этим проходом не выполнялся. Новые свойства выбираются отдельным фильтром.
