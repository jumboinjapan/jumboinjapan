## Исполнение и проверка

Схема: один POST, затем независимый GET; все прежние поля схемы совпали.
Родитель создан существующим `poi:jg-intake`: один POST, подтверждённое чтением
состояние `verified`. Связи — существующим `poi:jg-copy -- --packet FILE --write`:
восемь PATCH, восемь подтверждённых исходов. Никакого отдельного писателя POI.

Свежий снимок после операции: 1146 записей против 1145 до неё, включая служебные.
Все прежние поля остальных записей совпали. У восьми целей изменились только
`POI Geography`, а у станции дополнительно `Parent POI` и пояснение в Notes.
Прежние описания, статусы, координаты, типы и префектуры точки сохранены.
Повторный расчёт связей дал восемь `noChange` и ноль PATCH.

В рабочей админке проверены поиск POI-001251 по Яманаси и Сидзуока (одна
карточка в каждой выборке), восемь связей, переход к музею вне выбранной
префектуры и возврат без сброса фильтра. Мобильная ширина 390 px — без
горизонтального переполнения; ошибок JavaScript не обнаружено.

До записи сухой прогон обнаружил дефект передачи досье v2: путь `--facts`
терял evidence, copyReview и subjectAssessment. Исправлена передача трёх
полей; правила Intake сохранены. Сквозной тест CLI — 27 проверок, география —
181; три возврата дефекта в отдельной копии остановлены именованным
утверждением. Непрерывный `npm run verify` на Node 22.23.0, включая build, —
exit 0. Код исправления и реестр зафиксированы в `b9b04e6`.
