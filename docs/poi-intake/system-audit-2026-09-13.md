## Контракт изменения

Область: общий reader доказательств, досье нескольких источников, дополнение
известной записи, проверяемое исправление фактов, редакторская приёмка и
документация новых адаптеров. Сохраняем Intake, matcher, resolver, taxonomy,
координатную политику, журнал и независимое чтение. Не создаём новый writer.

Ошибка, которую устраняем: портал найден → новый POI либо skip; всё остальное
остаётся в голове агента. Теперь существующая запись получает самостоятельный
путь дополнения, который учитывает каждый новый факт и сохраняет историю старых.
Входы проверяются до эффектов; при частичном отказе сохраняется проверенный
префикс, остаток останавливается без автоматического отката.

## Границы доказательства

Regex и список флагов не удостоверяют смысл. Источник проверяет фактолог,
текст — отдельный редактор; журнал исполнения связывает их с реальными задачами.
Текстовые имена в JSON сами по себе не доказывают независимость исполнителей.
Новые внешние сайты не сканировались и существующая база не переписывалась.
Общий reader/досье/sync готовы для интеграции; конкретному порталу нужны
свой селектор, политика доступа и canary. Автопубликация не включена.

## Проверка реализации

Новая suite `tests/poi-fact-sync.mjs`: 52 именованных сценария. Создание и
дополнение проходят настоящие `ingestPoi` и `airtable-store` с подставным HTTP:
базовые поля сохранены, исход проверен независимым чтением, повтор и потерянный
ответ не порождают второй PATCH. Это доказательство исполнения кода, не живая
миграция или проверка литературного качества сгенерированного текста.

Девять мутаций на отдельной копии вне репозитория убиты соответствующими
именованными проверками. Положительный контроль — та же копия без мутации.
Проверены потеря истории, пропуск входящего факта, понижение требования к
источнику, самоприёмка автора, дрейф записи, конфликт в описании, пропуск
редакторской проверки в Core, потеря header/footer и постоянное хранение Google.

Непрерывный `npm run verify` на Node 22.23.0 до последнего запрета Google:
exit 0, включая build (`verify-frozen.log`, `verify-frozen.exit`). После него
добавлены общий guard, 51-й сценарий и девятая мутация; их проверки прошли.
При просмотре итогового отчёта исправлен признак неизменности публичного текста:
запись черновика тоже оставляет публичный текст прежним. Добавлен 52-й сценарий;
начатый verify остановлен до изменения исходников. Финальный непрерывный прогон
сохраняется отдельно в `verify-final-tree.log` и `verify-final-tree.exit`.
Он завершился с exit 0: все 78 тестовых наборов, typecheck, проверки документов
и данных, production build. Сверка SHA-256 подтвердила неизменность всех 791
учтённых файлов на протяжении прогона. Lint: 0 ошибок, 126 предупреждений;
предупреждения не объявляются исправленными этим пакетом. После прогона в этом
документе добавлен только результат проверки.
Все логи и результаты —
`tmp/poi-cross-portal-audit-2026-09-13/`.

в старой изолированной CLI-фикстуре: загрузка документов стала ленивой,
