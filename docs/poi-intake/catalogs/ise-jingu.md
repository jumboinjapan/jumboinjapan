# Исэ Дзингу: вложенность и состав по картам владельца

Решение владельца от 11.09.2026: общий родитель **Исэ Дзингу**, внутри него
**Найку** и **Гэку**, внутри каждой территории — самостоятельные места с карты.
Система данных допускает такую вложенность. Уплощать её до одного уровня не нужно.
Уточнение «(Найку)» или «(Гэку)» остаётся полезным для одинаковых названий,
но не заменяет поле `Parent POI`.

**Последнее решение владельца 11.09.2026:** «Пока оставить общего родителя без
регистрации». Общий Исэ Дзингу отложен; Найку и Гэку созданы отдельно, без связи
с несуществующей записью общего родителя. Повторный вопрос о его точке не нужен.

**Проверенное состояние:** Найку POI-000987, Гэку POI-000988, музей Сэнгукан

## Найку: 13 именованных элементов

Для этих элементов непосредственный родитель — Найку, не общий Исэ Дзингу.
При подготовке карточек различать здание, место поклонения и доступный вход.

| Подпись карты | Предмет и существенное ограничение |
|---|---|
| Shogu / Main sanctuary | Главное святилище. Место поклонения снаружи; не обещать вход во внутренний двор |
| Kodenchi | Соседняя площадка периодического переноса главного святилища; не называть общедоступными руинами |
| Aramatsuri-no-miya | Отдельное святилище на территории Найку |
| Geheiden | Сокровищница; самостоятельный архитектурный предмет, посещение внутри не подтверждено |
| Imbiyaden | Ритуальная кухня; не ресторан и не общедоступная кухня |
| Mishine-no-mikura | Хранилище риса для подношений; не обещать посещение внутри |
| Kaguraden | Зал молитв и кагуры; условия участия в обрядах проверять отдельно |
| Sanshuden | Дом отдыха паломников; сервисная функция хранится в фактах |
| Ujibashi Bridge | Мост Удзи у входа в Найку; мост и вся территория — разные предметы |
| Kazahinomi-no-miya | Отдельное святилище; не сливать с Kaze-no-miya в Гэку |
| Takimatsuri-no-kami | Место почитания божества реки |
| Mitarashi | Место омовения у реки Исудзу; не карточка всей реки |
| Temizusha | Место ритуального омовения; одинаковый значок сам по себе не доказывает несколько самостоятельных POI |

## Гэку: 12 именованных элементов

Непосредственный родитель — Гэку. Одинаковые имена Shogu, Kodenchi, Kaguraden,
Imbiyaden и Temizusha не означают совпадения с объектами Найку.

| Подпись карты | Предмет и существенное ограничение |
|---|---|
| Shogu / Main sanctuary | Главное святилище Гэку; внутренний двор закрыт для обычного посещения |
| Kodenchi | Площадка периодического переноса святилища Гэку |
| Mikeden | Зал ритуальных подношений пищи; не доступная посетителям трапезная |
| Imbiyaden | Ритуальная кухня Гэку; доступ внутрь не подтверждён |
| Kaguraden | Зал молитв и кагуры Гэку |
| Kaze-no-miya | Отдельное святилище на территории Гэку |
| Taka-no-miya | Святилище на возвышенности; карта указывает лестницу, учитывать доступность маршрута |
| Tsuchi-no-miya | Отдельное святилище на территории Гэку |
| Hiyokebashi Bridge | Входные мосты: пояснение карты использует множественное число. Число отдельных карточек установить по реальным объектам |
| Magatamaike Pond | Пруд Магатамаикэ |
| Sengukan | Музей сэнгу; часы и текущую работу сверить отдельно |
| Temizusha | Места омовения; не размножать карточки по повторённым значкам без проверки |

Таким образом, разобраны 25 именованных элементов двух территорий. Это число
элементов карты, **не число готовых к созданию POI**: сервисные функции могут
остаться в досье, а одно групповое обозначение мостов требует уточнения состава.

## Окрестности на врезке Гэку

Не приписывать все объекты врезки территории Гэку. Географическая близость не
создаёт связь `Parent POI`.

| Подпись | Как учитывать |
|---|---|
| Tsukiyomi-no-miya — 月夜見宮 | Самостоятельное святилище вне территории Гэку; возможный прямой ребёнок общего Исэ Дзингу после сверки принадлежности |
| Tsukiyomi-no-miya — 月読宮 | Другое святилище. Отличаются кандзи и место: совпадение латиницы не основание объединять |
| Yamato-hime-no-miya — 倭姫宮 | Отдельное святилище вне обеих основных территорий |
| Jingu Museums | Три подписанных музея: 神宮徴古館, 神宮農業館, 神宮美術館. Не считать одним зданием или детьми Гэку |
| Jingu Kaikan (hotel) | Связанный гостиничный ресурс; не святилище и не ребёнок Найку по одному соседству |
| Okage Yokocho | Отдельная торговая территория у Найку. Сверить границы с уже существующей Охараимати POI-000698; не сливать и не связывать автоматически |

Общий Исэ Дзингу шире двух территорий: официальный сайт описывает объединение
125 святилищ. Это контекст родителя, **не поручение создать ещё 125 карточек**.

## Практическая информация, которую нельзя потерять

Сохранить в фактах соответствующей территории: входы и мосты, остановки
Naiku-mae/Geku-mae, станции на обзорной схеме, парковки, туалеты, места курения,
охрану и информационные пункты, доступность колясок, комнату матери и ребёнка,
камеры хранения и указанное на карте место временного размещения животных.
Не представлять значки инфраструктуры отдельными достопримечательностями.
Точное расположение, наличие услуги сегодня и условия пользования нуждаются
в актуальной сверке. Старые времена проезда из врезки не выдавать за расписание.

Контекст обряда переноса святилищ, омовений и молитвы сохранить отдельно от
логистики. Религиозные рассказы о происхождении и божествах помечать как традицию,
а не установленную дату исторического события. Нарисованный объект не даёт
точных координат: точку проверять по самостоятельному картографическому источнику.
