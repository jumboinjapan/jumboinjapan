# Типы POI после импорта Visit Hokkaido

14.09.2026. Заполнены канонические типы **19 существующих карточек**, затронутых первыми 100 статьями Visit Hokkaido. Все 32 новых POI предыдущего завершающего прохода уже имели тип; ошибка находилась в обновлении старых записей.

Общий `poi:sync` обновлял факты, но не классификацию. Теперь он принимает проверенное предложение для пустого `POI Type`, связывает тип с предметом и фактами, проверяет действующий реестр и живую схему. Уже записанный канонический тип этим путём заменить нельзя. В результате явно показываются новый тип и необходимость дальнейшего разбора, если классификация осталась неопределённой.

Состав базы: **1134 неслужебных POI**. Канонических типов стало 693 (было 674); точных старых соответствий — 171, требующих уточнения — 270 (было 289). Все остальные записи сохранены. По ответу владельца эти 270 старых карточек остаются до внедрения многослойной матрицы.

## Сохранность и приёмка

Схема, старые категории, имена, координаты, связи, основной Source Key, статусы и все тексты описаний не менялись. Факты, история и набор источников сохранены. У 18 карточек Notes совпадает побайтно. У музея пива Саппоро общий merge убрал четыре повторения одинаковых ссылок в двух фактах: наборы ссылок и всё остальное досье совпадают, что отдельно подтвердил редактор.

Автор предложил типы по уже собранным материалам; независимый редактор проверил все 19. Для смотрового центра Кусиро выбран «Общественное пространство»: карточка описывает всё здание с экспозицией, а тип «Смотровая точка» по действующему реестру исключает здание целиком. Принадлежность к нескольким функциям будет решаться матрицей.

Проверенный код: `d01d9523a3e4bb2321b0cec0ff758e299cd9beba`. `npm run verify` на Node 22.23.0 завершён с кодом 0. Сюита `poi-fact-sync` — 71 именованный сценарий; шесть мутаций защит остановлены. Живой dry-run проверил все 19 строк и схему без PATCH; рабочая серия выполнила 19 подтверждённых обновлений. Независимое чтение проверило каждое предложенное поле, сохранность остальных и результат общего `readPoiCategory`. Повторная полная сверка категорий подтвердила уменьшение остатка ровно на 19. Запросов Google и отдельного модельного API в этом проходе не было.

В полном `verify` живую базу читали стадии `check:copy`, `check:canon`, `check:polivanov`, `check:poi`, `check:images` и `build`; записи эти стадии не выполняли. После обновления ещё один живой `check:poi` завершился с кодом 0: поломок нет. Прежнее предупреждение «366 POI без категории» относится к старому полю категории и не отражает канонические типы; оно было таким же до записи. Остаток для матрицы — 270, по общему читателю `poi:categories`. При работе над матрицей следует согласовать эту старую диагностическую метрику с общим читателем.
