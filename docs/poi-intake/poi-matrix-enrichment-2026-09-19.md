# Приёмка обогащения POI, 19.09.2026

**Частичная приёмка: 80 записаны, три предложения оставлены без записи.**
Claude подготовил 83 предложения из двух выбранных партий по 50:
41 из первой партии, 33 из второй и девять ранее отложенных.
Ещё 17 из второй партии отложены самим автором. Закон сохранения:
100 выбранных = 80 записанных + 3 отклонённых при приёмке + 17 отложенных.

## Что сохранено

867 входящих фактов и 406 свойств матрицы у 80 POI. Использованы итоговые
пакеты Claude с независимой редакторской проверкой и подписями итоговых
документов. Codex проверил передачу, ограничения, спорные случаи и свежую
базу; трём спорным строкам не выдал допуск. Содержимое принятых строк
и подписи не переписывались. Полный повтор исследования источников не проводился.

Писатель — штатный `poi:sync`, пакет `poi-fact-sync/v1`. Шесть пакетов:
25 / 16 / 22 / 1 / 7 / 9. Изменены только Notes и POI Matrix.
Тексты RU/EN находятся внутри досье; поля черновых и опубликованных описаний,
координаты, ссылки Website и статусы этим проходом не менялись.
Матрица есть у 807 из 1135 обычных POI; остаток — 328.
Системные 11 записей исключены из знаменателя. Это полнота наличия матрицы,
а не доказательство полноты каждого досье или набора свойств.
