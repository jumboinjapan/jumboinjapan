# Архив независимых аудитов POI

Эта папка хранит исходные задания и отчёты независимых аудитов. Они фиксируют состояние
проекта на момент проверки и не описывают текущий статус парсера.

Текущий статус, неизменный знаменатель и очередь работ ведутся в
[`parser-completion-ledger.md`](../parser-completion-ledger.md). Если значение из отчёта
аудита расходится с реестром, актуален реестр; исходный отчёт при этом не переписывается.
