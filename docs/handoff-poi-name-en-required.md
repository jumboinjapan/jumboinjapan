# Хандофф ветке POI: английское название обязательно наравне с русским

Решение владельца, 9 августа 2026. Записано по итогам разбора POI-000375
(«Золотой зал храма Тюсондзи», английского названия нет).

## Откуда взялось «не обязательно»

В редакторе названия стояла подсказка «Английское название — не
обязательно». Это перевод исходной английской строки `Optional English
title`, которая жила в панели с самого начала и никем не пересматривалась.
Волна 1 перевела её дословно вместе с остальным интерфейсом — и тем самым
закрепила как правило то, что было просто заглушкой.

Подсказка убрана в этой ветке (коммит с этим файлом). Само правило —
работа конвейера.

## Что нужно сделать в ветке POI

### 1. Канон: пара обязательна и для названий

`src/lib/poi-canon.ts`, функция `applyCanon`. Сейчас парой требуются
только описания:

```ts
if (descriptionRu && !descriptionEn) {
  push('descriptionEn', 'error', 'Есть русское описание, нет английского — описание заводится только парой')
}
```

Нужно такое же правило для названий:

```ts
if (nameRu && !input.nameEn?.trim()) {
  push('nameEn', 'error', 'Есть русское название, нет английского — название заводится только парой')
}
```

Внимание на два места, которые от этого поедут:

- **Служебные записи.** Правило про описания намеренно не мешает заглушкам:
  у них описания нет вовсе. С названиями так не выйдет — русское название
  есть у всех. Либо служебные записи исключаются явно, либо им заводится
  английское название тоже.
- **`tests/poi-ingest.mjs`.** Фикстуры без `nameEn` начнут падать. Считать
  падение ожидаемым нельзя: тест должен быть обновлён вместе с правилом,
  иначе красный прогон станет привычным фоном.

### 2. Исследователь должен возвращать оба названия

`src/lib/poi-intake.ts`, `RESEARCH_SYSTEM_PROMPT`. Там уже стоит «ОБА языка
обязательны» про описания — то же самое нужно про названия, иначе канон
начнёт отбивать записи, которые конвейер физически не может собрать.
Ровно этот сценарий уже был с описаниями: правило ввели раньше, чем
исследователь научился отдавать пару, и приём встал.

### 3. Долг: 29 записей из 418

Замер 9 августа на живой базе: 29 записей с русским названием и без
английского, обратных случаев ноль. Список видно в панели — фильтр
«Без названия EN» на экране POI.

Дозаполнять — скриптом через `ingestPoi()`, как договаривались: intake идёт
одной расчёской. Романизация по канону: **без макронов** (`Chusonji`, не
`Chūsonji`), британская норма написания.

Пока долг не закрыт, правило из пункта 1 сломает правку существующих
записей, если поставить его жёстко на весь путь. Порядок безопасный:
сначала дозаполнить 29, потом включить ошибку приёма.

## Что уже сделано в ветке админки

- Подсказка «не обязательно» убрана, вместо неё пример по канону:
  `Например, Konjikido Hall, Chusonji`.
- На экране POI появился фильтр и счётчик «Без названия EN» — долг видно
  и можно закрывать пачкой.
- Сохранение названия без английского проходит, но говорит об этом прямо:
  «Название сохранено. Английского названия нет — по канону оно
  обязательно наравне с русским». Блокировать правку существующих записей
  намеренно не стали: иначе, чтобы поправить русское название, пришлось бы
  сначала придумать английское.
