# Канон текста jumboinjapan.com — блок для любой сущности, компилирующей тексты

Зафиксировано 29.07.2026. Этот файл — единый источник для **вставки в промпты**: скиллы-копирайтеры, системные промпты генераторов в коде, агенты OpenClaw, инструкции подрядчикам. Машиночитаемая версия лимитов — `src/lib/copy-limits.ts`, проверка — `npm run check:copy`.

Правило вставки: копировать блок ниже целиком, не пересказывать. Пересказ теряет числа.

---

## 1. Длина: у каждой роли есть предел

Числа замерены по фактической ёмкости строки на мобильном (390 px — узкое место вёрстки), а не назначены на глаз. «Комфортно» — текст ложится в комфортное число строк. «Предел» — на строку больше; дальше блок ломается.

| Роль | Комфортно | Предел | Что ломается за пределом |
|---|---|---|---|
| Заголовок героя | 36 | 54 | Съедает первый экран |
| Заголовок страницы (h1) | 40 | 60 | Содержание уезжает за сгиб |
| Шапка раздела (h2) | 44 | 66 | Читается как абзац, набранный крупно |
| Заголовок карточки (h3) | 26 | 46 | Карточка растёт и рвёт ряд сетки |
| Метка над заголовком | 32 | 38 | Прописная разрядка в две строки — шум |
| Лид-абзац | 120 | 160 | Это уже не подводка, а первый абзац |
| Описание карточки | 140 | 200 | Ряд выравнивается по самой высокой |
| Вводный текст маршрута | 420 | 700 | Конкурирует с программой ниже |
| Вопрос FAQ | 56 | 84 | Не читается в свёрнутом виде |
| Ответ FAQ | 400 | 700 | Значит, вопросов на самом деле два |
| Надпись на кнопке | 20 | 28 | Кнопка растягивается на всю колонку |
| SEO-заголовок | 55 | 60 | Выдача обрезает хвост |
| SEO-описание | 150 | 160 | Выдача обрезает хвост |

**Главное правило: длинный заголовок не лечится уменьшением кегля.** Кегль — часть иерархии; подгонять его под текст значит разрушать иерархию ради одного заголовка. Лечится текст: длинное уходит в лид под заголовком.

Знаки считаются с пробелами, двойные схлопываются (`copyLength()` в `copy-limits.ts`). Для каждого сданного текста указывается длина и роль. За «комфортом» — предупредить явно и дать сокращённый вариант. За «пределом» — сокращённый вариант обязателен, длинный не предлагать вовсе. Роль неочевидна — спросить, а не угадывать: от роли предел меняется вдвое.

## 2. Типографика: что делает система, а что автор

Сайт расставляет на рендере (`typoDeep`, `src/lib/typography.ts`) — руками НЕ писать:

- неразрывные пробелы (после в, к, с, о, у, и, а, я; перед тире; между числом и единицей);
- многоточие вместо трёх точек;
- схлопывание сдвоенных пробелов;
- дефис в роли тире между словами.

Система НЕ трогает — писать сразу правильно:

- кавычки «ёлочки», внутри них „лапки“. Прямые `"` и английские `“ ”` — ошибка;
- диапазоны коротким тире без пробелов: 1–2 дня, 09:00–17:00, ¥3 500–7 500, 2026–2027. Дефис в диапазоне — ошибка;
- десятичная запятая: 2,5 часа (не 2.5);
- разряды пробелом: 15 000 человек;
- даты: 15 марта 2026 года в тексте, 15.03.2026 в таблицах;
- наращение: 5-й, 2-го, 90-е (не 90-ые); XXI век без наращения.

## 3. Каноны проекта

- **Заголовки.** В русском заголовке прописная только у первого слова и имён собственных: «Япония — первое открытие», не «Первое Открытие».
- **Транслитерация** — Поливанов (Дзуйходэн, Мацусима, Тэндзин, Кисю). Исключение по SEO: «Хаконе», не «Хаконэ», включая производные.
- **Виды транспорта** — только эти термины: Самостоятельно / Общественный транспорт / Частный транспорт / Заказной транспорт / ЖД / Авиа. Запрещены: «автомобиль с гидом», «машина с гидом», «гид-водитель».
- **Продолжительность тура** не выносится в тексты: число дней — переменный параметр под клиента, а не свойство тура.
- **Тон** — деликатный консьерж. Повелительное наклонение к клиенту запрещено: не «идите», «попробуйте», «возьмите». Кнопки-инфинитивы допустимы («Обсудить маршрут»).
- **Запрещённые слова** без доказательства за ними: уникальный, незабываемый, премиальный, является, осуществлять, данный, в настоящее время.

## 5. Уроки правок владельца

Раздел пополняется после КАЖДОЙ правки текста рукой владельца. Правка — это не только новый текст, но и правило, которое за ней стоит; без записи оно теряется вместе с сессией, и следующий агент повторяет ту же ошибку.

**Метка роли в начале строки** говорит, кого урок касается: `[все]` — сквозное правило для любого текста сайта, остальные — только для своей роли. Выжимка под конкретного агента собирается командой:

```bash
npm run copy-canon -- --role faq        # сквозные + правила FAQ
npm run copy-canon -- --role заголовки  # сквозные + правила заголовков
npm run copy-canon -- --roles           # какие роли вообще есть и сколько уроков в каждой
```

Источник правды один — этот файл. Разносить уроки по отдельным файлам под каждого агента нельзя: сквозных правил больше половины, и копии разойдутся.

Сырьё для новых уроков — `npm run collect:copy-edits` (пары «было → стало» из истории git). Скрипт даёт материал, правило формулирует человек или агент.

Формат: метка, правило одной строкой, под ним пример из реальной правки.

`[все]` **Японские топонимы не склоняются.** Исключения — Токио, Киото, Осака.
→ «от Гинзы до Сибуя» → «от Гинза до Сибуя»; «у статуи Хатико в Сибуе» → «в Сибуя».

`[все]` **Обещание без доказательства вырезается**, даже если звучит скромно. Тот же класс, что «уникальный» из стоп-листа.
→ «Авторские форматы туров, проверенные временем» → «Авторские форматы туров».

`[все]` **Слово не повторяется в пределах одного экрана.** Проверять не абзац, а видимую область.
→ «Авторские поездки из Токио…» отклонено: «Авторские маршруты» стоит строкой выше.

`[все]` **Голос — первое лицо единственного числа.** «Мы» допустимо, только когда это гид и гость вместе («мы с вами решаем»), но не как компания.
→ «Мы расскажем не только о маршруте» → «я расскажу».

`[все]` **«Услуги», а не «сервис».** «Сервис» тянет корпоративный оттенок, у частного гида его быть не должно.
→ «Формат предоставляемого сервиса» → «Формат предоставляемых услуг».

`[все]` **Текст от владельца — черновик.** Опечатки, пропущенная пунктуация, сдвоенные пробелы, слипшиеся абзацы правятся молча, но в отчёте перечисляется, что именно изменено: иначе правка выглядит как самовольная редактура.

`[все]` **Если блок не дочитывают — резать блок, а не сокращать текст по кругу.**
→ «Подход»: две колонки прозы → одна фраза → раздел удалён целиком.

`[все]` **Приём противопоставления запрещён.** Конструкции «не то, а это», «не просто…, а…», «а не» звучат искусственно: из всех возможных контрастов машина берёт самый очевидный, и текст выдаёт себя. Утверждать напрямую, без отрицаемой половины.
→ «Этот день о том, чтобы побыть рядом с горой, а не отметиться на смотровой» — так писать нельзя.

`[все]` **Не строить текст на предположениях о вкусах гостя.** Мы не знаем, чего он хочет: кому-то нужна именно «погоня за кадром». Описывать, что есть, и не оценивать, что из этого правильно.
→ «для тех, кто любит тишину, а не толпу» — так писать нельзя.

`[все]` **Не озвучивать риск, ради которого гость и едет.** Оговорка «гора открывается не каждому» продаёт сомнение: человек едет ради Фудзи и после такого заголовка уходит смотреть другой тур. Ограничения обсуждаются лично, а не в витрине.

`[все]` **Логистика не продаёт.** Ранний выезд, пересадки, очереди, расписания — это условия работы, а не достоинство тура. В карточках формата логистика допустима как удобство («частный транспорт — весь день в одной машине»), в тексте — нет.

`[все]` **Кальки с английского запрещены.** «День собирается из…», «гора держит горизонт», «это часть правды о маршруте» — конструкции, которых в живой русской речи нет. Проверка простая: так сказали бы вслух?

`[все]` **Не изобретать образы там, где есть точное слово.** «Лавовые леса», «дома под соломой» — придуманные сочетания, читаются как ошибка перевода. Правильно: «лес на застывшей лаве», «дома с соломенными крышами».

`[маршруты]` **Блок «Специфика тура» описывает специфику именно этого маршрута**, а не общие слова про погоду и темп. Специфику знает владелец: у Фудзи это изобилие мест, которых заведомо больше, чем помещается в день, и возможность увидеть гору с разных сторон. Не знаешь специфику — спроси, а не придумывай.

`[заголовки]` **Шапка раздела — утверждение, а не вопрос**, если под ней уже стоит выбор или анкета: вопрос сверху и вопрос снизу спорят.
→ «Какой формат путешествия ближе именно вам» → «Авторские форматы туров».

`[заголовки]` **Точка в конце заголовка не ставится.** Единственное исключение — эйлайн героя («Япония в деталях.»).

`[FAQ]` **Вопрос получает прямой ответ.** Философия — под свой вопрос, иначе разметка FAQPage отдаёт поиску рассуждение вместо ответа.
→ на «Можно ли адаптировать маршрут под интересы группы?» ответ снова начинается с «Да».

`[кнопки]` **Кнопка называет то, что обещает текст рядом.**
→ текст про макет программы на почту + кнопка «Подобрать формат» → «Получить маршрут».
