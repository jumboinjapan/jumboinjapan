# Границы runtime и техническая очистка

Актуальная схема после пакета 1, 25.09.2026.

## Исполняемый код

- `src/proxy.ts` обслуживает только `/admin/:path*` и `/api/admin/:path*`.
  Авторизация, OAuth и закрывающие кэш/индексацию заголовки сохранены.
  Старые публичные URL перенаправляет `next.config.ts` до proxy.
- A/B-cookie Хаконе больше не присваивается. Старый cookie не читается и
  истечёт у посетителей по прежнему сроку; отдельный обработчик удаления не нужен.
- Sitemap создаёт только `src/app/sitemap.ts`. Пакет `next-sitemap` удалён.
- `src/lib/airtable-field-equality.mjs` — общий чистый компаратор Airtable.
  Intake/матрица используют его напрямую. CLI `verified-write.mjs` импортирует
  и реэкспортирует ту же функцию, сохраняя прежний интерфейс и файловый журнал.
  Импорт сравнения не должен подключать файловые операции CLI.
- PDF-обработчики сохраняют включение фотографий и шрифтов в `next.config.ts`.
  Узкое временное исключение `public` из Telegram tracing больше не нужно:
  сам путь к динамическому файловому журналу разорван.

`tests/server-intake-boundary.mjs` импортирует настоящий Intake и отклоняет
подключение CLI writer/journal. После `next build` команда `npm run build`
выполняет `scripts/check-runtime-bundles.mjs`: функции не должны содержать
`tmp`, тесты, резервные выгрузки или архив исходников. Telegram дополнительно
не должен содержать фотографии сайта и CLI-журнал. Конфигурация POI остаётся
доступна своим runtime-потребителям.

## Отработавшие файлы

Удалены пять неподключённых UI-компонентов: `PoiSheet`, `ExperienceCard`,
`ImageCarousel`, `PoiCard`, `PoiCarousel`. Восстановление — через Git.
Семь законченных разовых скриптов хранятся в
[неисполняемом архиве](archive/scripts/README.md), а не среди рабочих CLI.

## За пределами пакета 1

Правила публикации, скрытие карточек по обложкам, таблицы и записи Airtable,
фотографии, архивирование событий и Vercel-проектов относятся к следующим
пакетам. Их состояние техническая очистка не меняет.

Telegram-уведомления о заявках и POI-бот — разные механизмы. Приём POI по
диагностике 25.09.2026 отключён настройками production; пакет 1 его не включает
и не удаляет. Состояние подключения устанавливается по настройкам и webhook,
а не по наличию названия переменной в Vercel.
