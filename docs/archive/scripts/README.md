# Архив завершённых скриптов

Зафиксирован 25.09.2026 в рамках технической очистки. Эти семь операций
были отмечены завершёнными или deprecated в `scripts/README.md` до переноса.

Файлы сохранены побайтно с расширением `.mjs.txt`: это исторические исходники,
а не работающие CLI. `manifest.json` содержит исходный путь и SHA-256 каждого
снимка. Старые относительные импорты и команды внутри снимков относятся к их
исходному расположению; не запускайте снимок как программу.

Историю и исходное окружение можно изучить через Git (базовый коммит `258b061`).
Возврат операции требует нового плана под актуальную схему и состояние данных.
Не восстанавливайте старый seed для текущего обслуживания базы.

Таблица `Services (deprecated)` уже переименована; историческая пометка о том,
что переименование ещё требуется, в снимке сохранена как часть оригинала.
Ни таблицы, ни записи этим переносом не менялись.
