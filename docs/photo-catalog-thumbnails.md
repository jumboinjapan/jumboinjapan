# Фотографии в тестовом каталоге POI

Дата: 2026-09-23. Поверхность: редактор остановок маршрута, ветка
`codex/route-poi-picker`, Vercel Preview.

## Контракт

- Dropbox-реестр сохраняет личность архива и права на актив.
- Веб-файл хранится в `public/tours/photo-library/` под неизменяемым именем с хешем.
- `PhotoUsages` связывает один веб-вариант с одной записью POI.
- Каталог показывает изображение только при `Status = Selected` или `Published`, безопасном
  относительном `Public Path` и ровно одной связи `POI`.
- Две видимые записи для одного POI считаются неоднозначностью: каталог оставляет этот POI
  без изображения, пока данные не исправлены.
- Отсутствие фотографии не скрывает POI и не мешает поиску или добавлению в маршрут.

## Первая партия

Пять фотографий Эносимы связаны с POI для маяка «Морская свеча», улицы Бэндзайтэн
Накамисэ, пещер Ивая, сада Самюэля Кокинга и святилища Эносима. В тестовом каталоге
они используются как компактные превью 4:3; исходники остаются в Dropbox.

Публикация выполняется в таком порядке: экспорт веб-файлов → Vercel Preview → проверка
URL → запись `Public Path`, `Alt RU`, статуса и подтверждённых прав → новое чтение Airtable.
Production-сайт этой операцией не изменяется.
