# Данные предпросмотра маршрутов

Источник программы — Airtable: `Routes`, `Route Stops`, `POI` и `Tickets`.
Ветка дизайна: `codex/tour-design-system`; Vercel project: `jumboinjapan`.
Постоянный адрес: https://jumbo-design-preview-2026.vercel.app.
Выкладывать через обычный preview deployment, без `--prod`.

## Контракт

- В окружении `VERCEL_ENV=preview` публичные читатели маршрутов обходят
  `unstable_cache`; корневой layout вызывает `connection()` и не отдаёт
  HTML, зафиксированный при сборке. React `cache` объединяет только чтения
  внутри одного серверного рендера.
- Открытие или перезагрузка маршрута читает текущую базу. Видимая вкладка
  обновляет серверные данные раз в 60 секунд и при возвращении к ней.
  Закрытая/фоновая вкладка не опрашивает базу. Это опрос, не webhook:
  применяется после завершения следующего запроса Airtable.
- Все пять городских программ, включая Такао и Митаке, берут состав,
  порядок, фото и тексты из базы. Старые массивы остановок в страницах удалены.
  Пустая программа остаётся пустой; удалённые остановки не восстанавливаются.
- Все 12 загородных программ читают POI по ID остановок, независимо от
  `Site City`. Составная остановка без POI остаётся в программе.
- Текст: ручной текст остановки → утверждённое описание POI → исходное
  описание POI. Утверждённый текст не подменяется рабочим черновиком.
- Название, вводный текст и обложка маршрута используют заполненные поля
  `Routes`; оформление и запасные обложки остаются в коде дизайна.
- Каталоги подхватывают новые опубликованные дневные маршруты. Неизвестные
  черновики не открываются через публичный шаблон. Существующие макеты,
  чьи записи исторически имеют статус Draft, сохраняют прежнюю доступность.
  Многодневные страницы сохраняют правило `Status=Published`.
  В preview одинаковая обложка не скрывает опубликованный многодневный тур.
- Сбой Airtable в preview даёт ошибку чтения, а не старую кодовую программу.
  Изменения кода/дизайна и новые бинарные файлы по-прежнему требуют деплоя.
- Новые адреса дневных туров рендерятся динамически: пустой
  `generateStaticParams` несовместим с `connection()` при первом запросе
  нового адреса в preview. Production сохраняет кэш данных с тегами;
  существующие страницы сохраняют ISR и механизм сброса тегов. В этом изменении
  нет записей в Airtable, изменения статусов или публикации на основном домене.

## Проверка

`node tests/live-route-preview.mjs` проверяет чтение после изменения источника,
добавление/удаление остановок, порядок, наследование текста, составные остановки,
POI другого направления, статусы каталога и обновление видимой вкладки.
Для нового деплоя дополнительно сверять POI ID и порядок карточек с живой
Route Stops, HTTP-заголовок страницы `Cache-Control` и содержимое DOM.
