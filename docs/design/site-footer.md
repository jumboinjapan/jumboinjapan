# Общий футер: обновление композиции

Футер публичных страниц переработан по замечанию владельца от 2026-09-21.
Тёмный зелёно-графитовый фон завершает светлую страницу; фирменный знак
повторяет геометрию знака в шапке. Краткое описание сервиса стоит рядом
с брендом, навигация разделена на две группы по три ссылки. Почта, город
и Instagram собраны в контактной колонке. Стоимость и порядок обсуждения
услуг по-прежнему берутся из `serviceTerms.pricing`, но вынесены в нижнюю
строку с копирайтом.

Все прежние ссылки сохранены. Почта по-прежнему собирается только после
гидратации через `ObfuscatedEmail`; новых каналов связи не добавлено.
Названия групп связаны с `nav` через `aria-labelledby`. Все ссылки имеют
высоту не меньше 44px и видимый клавиатурный фокус. Анимация цвета отключена
при запросе reduced motion.

На широком экране четыре колонки; на планшете две; на телефоне бренд и
контакты занимают полную ширину, две группы навигации стоят рядом.
Резерв под закреплённую мобильную кнопку перенесён из светлого `AppShell`
в футер. Он учитывает safe area и breakpoint 1280px самой кнопки, поэтому
нижняя строка не закрывается и на промежуточной ширине 1024–1279px.
На `/contact` и `/profile` этот резерв отсутствует, как и сама кнопка.

Проверены 1440/1024/390/320px, страницы Хаконе, туров по Токио и контактов:
нет горизонтального переполнения, mailto и прежние адреса ссылок сохранены,
тач-цели не меньше 44px. На странице контактов нет лишнего нижнего отступа.

`npm run verify` прошёл с кодом 0 (`tmp/footer-album-verify.log`). Стадии,
требующие живую базу, штатно пропущены без ключей в рабочей копии. После
уточнения мобильного отступа также пройден ESLint двух затронутых компонентов
(`tmp/footer-album-focused-lint.log`); итоговая сборка включает эти изменения.
Контраст основного текста 13.14:1, вторичного 7.76:1, hover/focus 6.62:1.

и корректная mailto-ссылка после гидратации. Основной домен не изменён.
