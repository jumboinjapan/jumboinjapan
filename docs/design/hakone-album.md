# Хаконе: архитектурный альбом, вторая версия

21.09.2026. Пересборка по поручению владельца после разбора макета Claude Design
из `Hakone itinerary layout.zip`. Референс использован для композиции;
его React-обвязка, заглушки фотографий и неработающие ссылки не переносились.

## Действующая композиция

- Локальная Cormorant Garamond для крупных заголовков Хаконе. Основной текст
  остаётся гротеском. Глобальный выбор Lora для остальных страниц не менялся.
- Компактная обложка: название и строка «Около 10 часов», затем невысокая панорама.
  По замечанию владельца удалены остальные факты и подпись «Последовательность поездки».
- Пять самостоятельных блоков программы. Первые два полных предложения
  описания видны сразу; полное описание, заметка гида, часы и билеты
  открываются прежним окном остановки. Порядок и тексты приходят из конструктора.
- Подходящие фотографии показаны у Овакудани и музея под открытым небом.
  По следующему поручению владельца у всех остановок одинаковый формат 3:2;
  для трёх отсутствующих снимков добавлены нейтральные подписанные плейсхолдеры.
  Текст и номер выровнены вместе по центру фотоблока, ниже 900px — один столбец.
- Светлые дополнения: три колонки, обед — две. Короткий текст виден сразу,
  продолжение и практические сведения раскрываются без повторения анонса.
  До 768px — один столбец.
- FAQ: заголовок слева, вопросы справа; на телефоне последовательный поток.
- Постоянная кнопка обращения и одна спокойная ссылка внизу сохранены.
  Сравнение тарифов и промежуточные призывы не возвращались.

## Данные и границы

Оформление ограничено Хаконе и вариантом `album` общего компонента маршрута.
Прежний вариант других туров не менялся. Записей в Airtable не было.
Из кратких фактов оставлена только продолжительность «Около 10 часов» из
существующего FAQ Хаконе. Это пока локальное редакционное значение.

Фотографии по POI используются только как локальный резерв при отсутствии
`photoPath` в конструкторе: `POI-000039` → `hakone-3.jpg`, `POI-000038` →
`hakone-2.jpg`. Они проверены визуально. Исторический seed с ошибочной
привязкой витражной башни к круизу не использовался и не менялся.

Дополнения Tenseien и рестораны пока локальные редакционные записи;
Pola и Lalique — действующие POI. Подключение дополнительных групп к админке
остаётся отдельной работой: [hakone-additions.md](hakone-additions.md).
Метаданные, canonical и структурированные данные сохранены.

## Верхнее пояснение и общая линия раскрытия

По следующему замечанию владельца «Подробнее» у дополнений и обеда выровнены
через CSS subgrid: общие строки подписи, заголовка, анонса и раскрытия.
Высота анонса определяется содержимым, без фиксированных высот; при раскрытии
одной карточки соседние ссылки сохраняют общую горизонталь. На телефоне
карточки возвращаются в естественный вертикальный поток.

Пояснение «О маршруте» перенесено в обложку справа от названия. Полное
вступление из конструктора раскрывается там же. На мобильных остаётся
компактное раскрытие, если вступление заполнено; пустого переключателя нет.
Прежний нижний блок удалён. На границе программы и дополнений оставлен
один разделитель — верхняя граница дополнений.

Проверены 320/390/768/1440px, раскрытие вступления, одинаковые координаты
ссылок «Подробнее» до и после раскрытия Pola, отсутствие горизонтального
переполнения и единственный разделитель после программы.

Живые проверки базы пропущены без локальных ключей; браузерная проверка
выполнялась отдельно с данными.
