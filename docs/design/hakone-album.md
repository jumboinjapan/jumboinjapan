# Хаконе: архитектурный альбом

21.09.2026. Владелец выбрал направление архитектурного альбома / Fine art
книги после просмотра нейтрального списка дополнений. Это локальный образец
на странице Хаконе; другие туры и общая навигация пока не переоформлены.

## Композиция

- Светлая бумага, графитовый текст, существующая шрифтовая пара. Обложка:
  крупное название слева, фотография без текстового наложения справа.
- Программа сразу после обложки. На широком экране слева фотография
  витражной башни, справа пять остановок из действующего конструктора.
  На телефоне сначала список остановок, затем фотография.
- В списке краткий визуальный анонс (две строки). Полное описание остаётся
  в HTML и в прежнем окне остановки вместе с часами, билетами и заметкой гида.
- Вступление из Routes сохранено в раскрываемой заметке после программы.
  Оно больше не отодвигает остановки вниз.
- Дополнения и обед — тёмный зелёный разворот с короткими названиями
  и подписями. Аккордеоны, данные музеев и ссылки сохраняются. От 900px
  две неравные колонки, ниже — одна. Нет произвольных фотографий,
  выдаваемых за снимки Tenseien, Pola, Lalique, Kihinkan или Kaikatei.
- Транспорт и похожие маршруты без теней и округлых карточек. Фотографии
  транспорта имеют формат 16:9. Сравнение тарифов не возвращается.
- Основное приглашение — постоянная кнопка. Внизу остаётся текстовая ссылка.

Фотографии из существующего public/: `hakone-hero.jpg` — обложка,
`hakone-2.jpg` — витражная башня музея под открытым небом. Файл проверен
визуально: старый seed ошибочно относил это фото к круизу. Seed и записи
конструктора в рамках оформления не менялись.

## Границы реализации

Для `IntercityRouteTimeline` добавлен явный вариант `album`, использованный
только в Хаконе. Прежний вариант остальных страниц остаётся по умолчанию.
Все остановки, порядок и основные тексты по-прежнему читаются из Airtable.
Редакционные дополнения и их будущая связь с конструктором описаны в
[hakone-additions.md](hakone-additions.md). Короткое отображаемое название
не заменяет полное имя POI. В базу ничего не записывалось.

Метаданные, canonical, TouristTrip, FAQ и ссылки на другие маршруты сохранены.
Изменения не опубликованы на основном сайте.

## Проверка

`npm run verify` завершился с кодом 0 (`tmp/hakone-album-verify.log`).
В этой рабочей копии нет ключей: живые проверки базы пропущены, имена
сверены по снимку. Браузерная проверка выполнена отдельно с данными маршрута:
320/390/768/900/1280/1440/1920px; горизонтального переполнения не обнаружено.
На 1440px программа начинается на отметке 621px от начала страницы,
на 390px — 595px. Две колонки дополнений начинаются с 900px.

Проверены открытие первой остановки, открытие последней с клавиатуры,
закрытие кнопкой и Escape, раскрытие Pola с описанием, часами и билетами.
Таблица билетов помещается при 320px. Контраст основных пар: текст на бумаге
5,32:1, подписи на тёмном фоне 6,88:1, заголовки 10,33:1.

Отдельная production-сборка с конфигурацией чтения данных завершилась с кодом 0
(`tmp/hakone-album-live-build.log`). Предпросмотр на 3101/3100 обновлён.
На 3101 подтверждены все пять остановок, отсутствие сломанных изображений
и прежний canonical. При сборке и просмотре выполнялись только чтения.
