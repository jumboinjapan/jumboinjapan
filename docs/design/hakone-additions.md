# Дополнения к туру Хаконе

Текущая визуальная версия: [архитектурный альбом](hakone-album.md),
выбранный владельцем 21.09.2026. Ниже — история устройства и данных блока;
равные колонки и прежняя светлая подача заменены альбомной композицией.

Режим: Read / Persuade. После основной программы посетитель выбирает,
что обсудить с гидом: дополнительную остановку или место для обеда.

## Подача

- Сразу после программы — дополнения и обед. Повторное приглашение с красной
  кнопкой удалено; якорь `#adapt` сохранён на группе дополнений.
- Постоянная кнопка в шапке (на телефоне — нижняя панель) остаётся основным
  приглашением. После логистики — одна спокойная текстовая ссылка на контакты
  с прежним якорем `#cta`, без рекламной карточки и повторного описания тура.
- Блок сравнения стоимости общественного и частного транспорта удалён целиком.
  Карточки форматов транспорта, маршрут и метаданные сохранены.
- «Что можно добавить» — один заголовок без надзаголовка, вступления и
  общей карточки про онсэн. Конкретные места показываются строками аккордеона.
- «Обед» — самостоятельная необязательная группа с тем же оформлением.
  При отсутствии заведений группа не выводится.
- От 900px группы стоят в двух равных столбцах: дополнения слева, обед
  справа. Ниже 900px идут друг за другом; единственная группа занимает
  всю ширину. Раскрытие одной группы не растягивает строки соседней.
- Все строки изначально закрыты. Внутри — описание, существенные условия,
  имеющиеся часы/билеты и ссылка на официальный сайт. Полный текст остаётся
  в серверном HTML; для раскрытия не нужен JavaScript.
- В каждой группе одновременно открывается одна строка. На телефоне строки
  допускают перенос названия.
- В русских читательских текстах не добавлять японские написания. Имена
  источников и служебные данные исходных записей этим правилом не изменяются.

## Данные и граница текущего этапа

Pola (`POI-000042`) и Lalique (`POI-000367`) читаются из существующих POI:
имя, утверждённое описание (с прежним fallback на исходное), часы и билеты.
Активные helper-точки из Route Stops сохраняются; совпадения с основным
маршрутом и дубли в дополнениях не выводятся.

Tenseien, Kihinkan и Kaikatei не найдены среди POI Хаконе и при поиске по
названиям в общей таблице. Сейчас это редакционные элементы **локального
предпросмотра**, не зарегистрированные POI и не значения из конструктора.
Их данные отдельно находятся в `src/data/hakone-additions.ts`.
В живую базу ничего не записывалось. Prada не добавляется: владелец подтвердил,
что имел в виду только музей Pola.

Следующий этап конструктора: выбирать существующий POI для каждого элемента,
задавать роль (основная остановка / дополнение / обед), порядок и короткую
маршрутную заметку. Для отсутствующих мест сначала пройти штатную регистрацию
POI; затем заменить редакционные элементы ссылками на записи. Названия,
описания и практические сведения не дублировать в маршруте. Точные поля
схемы определяются после проверки действующего редактора. До этой работы
управление всеми пятью рекомендациями через админку не заявляется.
В действующем `RouteStopsEditor` уже есть `Is Helper` и
`Helper Criteria Label`; отдельной роли для обеда в этом редакторе пока нет.

## Упрощение приглашений и логистики

По замечанию владельца удалены сравнение транспортных расходов, промежуточная
полоса «Хотите адаптировать…» и большая заключительная карточка. Вместо неё
оставлена текстовая ссылка «Обсудить поездку в Хаконе». Основное действие
по-прежнему доступно в постоянной навигации. Компонент удалённой полосы и его
стили также удалены; обе прежние якорные ссылки продолжают работать.

Число приглашений — решение интерфейса, а не требование поисковой оптимизации.
[Google](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)
рекомендует полезное содержание и понятную структуру для SEO и AI-поиска;
оснований сохранять повторяющиеся призывы ради этих целей нет.
Метаданные для поиска и [социальных превью](https://ogp.me/) не менялись.

Проверка этой правки: `npm run verify` завершился с кодом 0
(`tmp/hakone-quiet-verify.log`); живые проверки Airtable пропущены без ключей,
проверка имён выполнена по снимку. Отдельная сборка с конфигурацией данных
также завершилась с кодом 0 (`tmp/hakone-quiet-live-build.log`). При сборке
и просмотре страницы выполнялось только чтение, без записей в базу.
В браузере при 1280px и 390px проверены отсутствие удалённых блоков,
переполнения и переход оставшейся ссылки на `/contact`. Якоря `#adapt`
и `#cta` работают. Основной предпросмотр на порту 3101 обновлён и проверен
с пятью остановками маршрута и пятью дополнениями/заведениями.
