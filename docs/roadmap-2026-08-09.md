## Э0 · Влить гигиену

**Зачем.** Разблокирует всё остальное: без зелёного `npm run verify` и CI следующие этапы нечем проверять.

**До деплоя — одно действие.** Посмотреть, задан ли `TELEGRAM_OWNER_CHAT_ID` в Vercel Production. Раньше пустая переменная означала «пускать всех», теперь — «не пускать никого». Если её нет, бот приёма POI замолчит сразу после деплоя.

**Шаги.**

```
rm -f .git/HEAD.lock .git/objects/maintenance.lock
git fetch jj-hygiene.bundle chore/repo-hygiene-2026-08-09:chore/repo-hygiene-2026-08-09
git switch chore/repo-hygiene-2026-08-09
git merge main          # ваш 30b1d1a, конфликта не будет
npm ci && npm run verify
```

Дальше — превью-деплой Vercel (в ветке правится авторизация: матчер `proxy.ts` и обновление Next), проверка админки анонимным curl: `/admin` → 307, `/api/admin/...` → 401. Потом слияние в `main` и пуш.

**Готово, когда.** Actions зелёные на `main`, прод задеплоен, бот приёма POI отвечает на ваше сообщение, админка просит логин.

**Риск.** Средний — трогается авторизация. Снимается превью-деплоем.

**Объём.** Одна короткая сессия.

**Порядок.** Ветка от обновлённого `main`. Первый коммит — код и тесты вместе. Второй — портальный сборщик. Третий — `npm run verify` дополняется POI-тестами, а из `AGENTS.md` убирается строка про десять мёртвых команд.

**Риск.** Высокий: пишет в боевой Airtable. Проверять только на превью и только на заранее выбранной тестовой записи.

**Объём.** Одна-две сессии. Основное время — не код, а прогон бота на превью.

## Э3 · Импортёр Japan Travel

**Зачем.** Числится живым конвейером в README, не работает с 3 июля. Либо чинить, либо честно выключить — третьего состояния быть не должно.

**Что известно.** `parseIndexCandidates()` (`japantravel-events.ts:758`) строит кандидатов только из `Event` JSON-LD. На индексной странице его больше нет: остался `BreadcrumbList`, а данные уехали в HTML-экранированный hydration payload. Детальные страницы `Event` JSON-LD сохранили, значит `parseDetailPage()` скорее всего цел.

**Развилка — ваше решение.**

*Чинить.* Парсить hydration payload или разметку карточек на индексной странице. Работа осмысленная, но `japantravel-events.ts` — 1467 строк, и до починки парсера у рефакторинга нет базовой линии для сравнения решений. Порядок: сначала парсер, потом разделение модуля.

*Выключить.* Убрать три команды из `package.json`, переписать раздел README, оставить код с пометкой. Честно и дёшево. Вернуться можно в любой момент.

**Готово, когда.** Либо dry-run находит больше нуля кандидатов, либо README и `package.json` больше не обещают работающий конвейер.

**Объём.** Починка — сессия-две с сетевой отладкой. Вывод из эксплуатации — полчаса.

## Э4 · Счета

**Зачем.** 12 файлов, 6,2 МБ, ни одной строки в git. Работа в процессе, но бэкапа нет.

**Решение до коммита — `ipaexg.ttf`, 5,9 МБ.** Уедет в историю навсегда, оттуда его потом не вынуть без переписывания истории. Три варианта:

**Объём.** Зависит от того, сколько осталось доделать. Само вливание — полсессии.
