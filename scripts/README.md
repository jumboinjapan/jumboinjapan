# `scripts/` — карта

Читай это первым, если тебе поручили что-то запустить, починить или дописать
в этой папке. Здесь 35 файлов, и половина из них умеет писать в живой Airtable.

---

## 0. Три правила, нарушение которых стоит дорого

**Запись в POI идёт только через `ingestPoi()`.** Единственная дверь:
`src/lib/poi-ingest.ts`. Канон → идемпотентность по `Source Key` → гейт дублей
и родителя → запись **черновиком**. Своего пути записи не заводит ни один
скрипт, включая коллектор. Полный контракт — `docs/poi-intake-contract.md`.

**Dry-run по умолчанию, запись по флагу.** Ни один скрипт не должен писать
без явного `--write` / `--fix` / `--apply`. Если пишешь новый — держи это
правило: цена ошибки здесь измеряется в записях живой базы, а не в упавшем
прогоне. Известная мина, оставленная в наследство:
`import-japantravel-events-batched.mjs` имеет `dryRun: false` по умолчанию
и горизонт 400 дней — запуск без флагов означает 220 страниц с записью в прод.

**Текст в `Description (RU)` и `Description Approved (RU)` не пишет никто.**
Сайт рендерит `approvedRu` первым и без оглядки на `Copy Status`, поэтому
запись туда равносильна мгновенной публикации непроверенного текста.
Только `Description Draft (RU)` / `(EN)`.

## 1. Проверки — безопасны, ничего не меняют

Их можно запускать в любой момент и ставить в CI.

| Команда | Что проверяет | Когда падает |
|---|---|---|
| `npm run check:poi` | целостность живой базы POI: дубли, координаты, сироты, безопасность публикации | есть проблема уровня FAIL; WARN не роняет |
| `npm run check:polivanov` | транслитератор против 394 имён, написанных владельцем руками | доля совпадений упала ниже 45% — это тест на регрессию, а не на совершенство |
| `npm run check:polivanov-wd` | транслитератор против Wikidata | расхождения сверх порога |
| `npm run check:typography` | русская типографика в исходниках | найдены прямые кавычки, дефис вместо тире и т. п. |
| `npm run check:copy` | длина текстов по ролям (заголовок, карточка, мета) | текст длиннее предела своей роли |
| `npm run check:images` | ссылки на изображения не битые | файл не найден |
| `npm run check:admin-tokens` | цвет в админке берётся только из `--adm-*` | палитра Tailwind или `on-accent` на тинте |
| `npm run poi:gaps` | чего в базе не хватает по регионам и категориям | не падает, это отчёт |
| `npm run poi:sources` | профилирование источников и веса | не падает, это отчёт |

`check-poi-integrity.mjs` дополнительно умеет `-- --json` для машинного
разбора и `--fixture tmp/` для прогона на дампах вместо живой базы.

## 2. Сбор POI с порталов — `scripts/poi-portals/`

Единственная подсистема здесь, а не просто скрипт. Архитектура и юридическая
сторона — `docs/poi-portal-collector.md`.

```
registry.mjs          реестр источников, восемь порталов, список зафиксирован
                      владельцем 06.08.2026. Добавление источника = запись
                      в реестре, а не новый скрипт
      │
      ├── licence.commercial !== true → прогон пропускается
      ▼
lib/opendata-csv.mjs  адаптер 自治体標準オープンデータセット. Алиасы колонок,
                      потому что Осака отдаёт 58 колонок с полуширинными
                      скобками, Киото — 32 с полноширинными
      ▼
lib/scoring.mjs       чистая функция вход→решение, без I/O. Блокеры отдельно
                      от баллов. Нераспознанная категория = потолок review
      ▼
lib/dedupe.mjs        три ключа: sourceKey → координаты (гаверсинус) → имя
                      (триграммы). Не includes() — на «Сад» матчилось всё
      ▼
lib/enrich.mjs        каскад AI: правила (бесплатно, 45% категорий) →
                      классификатор → извлечение часов и цен
      ▼
collect-pois.mjs      CLI. Dry-run по умолчанию, --write только через ingestPoi
```

Полезное:

```bash
node scripts/poi-portals/collect-pois.mjs --portal bodik-osaka-tourism --out tmp/osaka.json
node scripts/poi-portals/collect-pois.mjs --portal bodik-osaka-tourism --dry-write   # весь конвейер, без записи
node scripts/poi-portals/collect-pois.mjs --portal bodik-osaka-tourism --monitor tmp/prev.json
```

Режим `--monitor` сравнивает прогон с прошлым снимком: added / removed / changed.
**По результатам мониторинга автоматически не делается ничего** — пропажа
объекта из выгрузки это чаще перестроение выгрузки, а не закрытие храма.
Список идёт человеку.

Имена собираются транслитерацией по Поливанову (`src/lib/polivanov.ts`) и
**всегда** помечаются в `Notes` как машинные: отличить «имя выбрал человек»
от «имя собрал скрипт» потом можно будет только по этой отметке.
Описания из источника не переносятся — права на текст не даёт ни один портал.

## 4. Канон текста — как агент получает свои правила

```bash
npm run copy-canon -- --roles            какие роли есть и сколько уроков
npm run copy-canon -- --role faq         сквозные правила + правила FAQ
npm run copy-canon -- --role faq --full  плюс разделы 1–4 целиком
npm run collect:copy-edits -- --md       пары «было → стало» из истории git
```

Источник — `docs/copy-canon-for-agents.md`. Уроки размечены по ролям
(`[все]`, `[заголовки]`, `[FAQ]`, `[кнопки]`), потому что правила про
заголовки бесполезны тому, кто пишет ответы FAQ, а заводить отдельный файл
под каждого агента нельзя: из одиннадцати уроков семь сквозные, и копии
разошлись бы через месяц.

Правки владельца — обучающий материал. Если он поправил твой текст руками,
правило записывается в канон, а не теряется вместе с сессией.

## 5. Что нужно знать про окружение

**Ключи.** Скрипты читают `.env.local` (или окружение): `AIRTABLE_TOKEN`,
`AIRTABLE_BASE_ID`, `OPENAI_API_KEY`, `OPENAI_MODEL`. Часть подхватывает их
через `@next/env`, часть разбирает файл сама — смотри шапку конкретного файла.

**Модель по умолчанию.** В коде местами захардкожен `gpt-4.1-mini`, снятый
с прайс-листа OpenAI. Задавай `OPENAI_MODEL` явно, на хардкод не рассчитывай.

**TypeScript из .mjs.** Скрипты импортируют `src/lib/*.ts` напрямую —
запускать через `node --experimental-strip-types`. По этой же причине модули,
которые тянут и Next, и скрипты (`poi-ingest.ts`, `poi-canon.ts`,
`admin-draft-generator.ts`), используют **относительные** импорты, а не
алиас `@/lib/...`: алиас резолвится только внутри Next.

**`scripts/` был в `.gitignore`** с 17 мая 2026 (коммит `0621f0c4`) — попал
туда за компанию с рабочими файлами агента OpenClaw. Из-за этого 17 файлов
из 35 в репозиторий не попали, включая весь `poi-portals/`. Если чего-то
не хватает на чистом клоне — причина эта.
