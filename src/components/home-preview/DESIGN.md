# Два макета главной

Предпросмотр, Persuade: помочь гостю выбрать масштаб поездки и открыть маршрут либо опросник.
Основа — архитектурный альбом существующих страниц туров: бумага #f4f1ea,
чернила #242923, подписи #66685f, линейки #d4d4c9; Lora для заголовков,
Geist для текста. Акцент сохраняет цвет основной кнопки сайта.

A: исходная главная и её содержимое, включая большую фотографию Токио.
Только локальная CSS-оболочка: компактнее отступы, единая мера текста,
размеры заголовков и фотографий, ровные линейки. Содержание не дублировать.
B: новый альбомный разворот с фотографией 3:2, оглавление из трёх форматов,
избранная поездка, портрет автора, процесс и раскрываемые вопросы.
Фотографии — существующие файлы сайта; никакого нового импорта или назначения в Airtable.

На узком экране одна колонка, изображения сохраняют пропорции, кнопки от 44px.
На широком экране контейнер ограничен 1360px. Без появления контента по скроллу.
Переключатель макетов — отдельная служебная полоса сверху, оба адреса noindex.
Основная страница / не изменяется, макеты закрыты в VERCEL_ENV=production.
